# -indoor-thermometer
ESP32を自宅温度計として運用しています.

# 1.概要

ESP32をUSB接続でLINUXサーバーにつないで温度を測定します。

温度表示は、サーバーと許可された端末間のみの表示とさせていただきます。


今回は、検証版なのでWindowsPCにUSBで接続し表示させています。
